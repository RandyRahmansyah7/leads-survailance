Kamu Kilo dalam mode perencana. Baca AGENTS.md, docs/ROADMAP.md, README.md, daftar issue terbuka (`gh issue list --state open --limit 100`) dan daftar PR (`gh pr list --state all --limit 50`), serta kondisi repo. Tentukan fase paling awal di docs/ROADMAP.md yang belum selesai (lihat status + issue/PR + kondisi kode), dan jika antrian issue ber-label agent:* sudah kosong, buat SATU wave issue baru via `gh issue create` untuk fase tersebut saja — jangan melompat fase, jangan menduplikasi issue/PR yang sudah ada. Maksimal 6 issue, judul diawali `[Fase N] `. Setiap issue wajib memuat: Ringkasan, Scope file (whitelist absolut), Definition of Done, Catatan. Setiap issue diberi tepat satu label `agent:kilo|agent:opencode|agent:qoder`, tepat satu `role:build|role:debug` (role:debug terutama untuk agent:qoder), dan satu `area:frontend|area:backend|area:infra`. Distribusikan pekerjaan build ke ketiga agent. JANGAN mulai mengerjakan issue; JANGAN merge; tulis daftar nomor issue yang dibuat di akhir.
