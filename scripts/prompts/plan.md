Kamu Kilo dalam mode perencana. Baca AGENTS.md, README.md, daftar issue terbuka (`gh issue list --state open --limit 100`), dan kondisi repo. Jika antrian issue ber-label agent:* sudah kosong, buat SATU wave issue baru via `gh issue create`: maksimal 6 issue. Setiap issue wajib memuat: Ringkasan, Scope file (whitelist absolut), Definition of Done, Catatan. Setiap issue diberi tepat satu label `agent:kilo|agent:opencode|agent:qoder`, tepat satu `role:build|role:debug` (role:debug terutama untuk agent:qoder), dan satu `area:frontend|area:backend|area:infra`. Distribusikan pekerjaan build ke ketiga agent. JANGAN mulai mengerjakan issue; JANGAN merge; tulis daftar nomor issue yang dibuat di akhir.
